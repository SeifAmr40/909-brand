## إزاي تبدّل الصور

### الطريقة الأسهل — صور في فولدر `images/`

1. افتح فولدر `images/` في الـ repo
2. ارفع صورتك (jpg أو png أو webp)
3. افتح `index.html` وابحث عن الـ `src` اللي عايز تبدله
4. بدّله كده:
   ```html
   src="images/اسم-صورتك.jpg"
   ```
